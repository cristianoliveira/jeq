# JEQ v0.1.0-rc.1

First release candidate for JEQ, a typed judgment CLI for scripts and agents.

## Highlights

- Native, typed TypeSafe judgments with `ask`, `validate`, `map`, `rate`, `reduce`, `rank`, and `gate` commands.
- JSON, NDJSON, TOON, and structured trace output suitable for pipelines.
- Nix package/app outputs and source installation paths.
- Reproducible GoReleaser archives for Linux and macOS on amd64 and arm64.
- `jeq version` reports the release version and source commit.

## Install

From a tagged source checkout:

```sh
nix run . -- version
nix profile install .#jeq
```

Go users can also install from source with `go install ./cmd/jeq`.

## Known limitations

- TypeSafe access requires `TYPESAFE_API_KEY`; commands that evaluate judgments make network requests.
- Windows artifacts, signing, provenance, Homebrew, and nixpkgs publication are out of scope.
- Choice probabilities are relative; they are not independent confidence scores.
- Release candidates are not a stability guarantee. Review generated evidence before automation.

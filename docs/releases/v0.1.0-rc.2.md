# jeq v0.1.0-rc.2

jeq v0.1.0-rc.2 makes streamed judgment pipelines faster, provider selection explicit, and command discovery easier for people and agents. This remains a prerelease. CLI compatibility may change before v0.1.0.

## Highlights

- `map` reads NDJSON incrementally, evaluates records with bounded concurrency, preserves input order, and stops with a deterministic valid output prefix on failure.
- Provider configuration supports explicit TypeSafe and Vercel AI Gateway profiles without putting credentials in command arguments or config files.
- `jeq examples ask|map|rate|rank|reduce|gate|validate` resolves directly to an offline canonical recipe before you spend an API request.
- New focused guides cover installation, getting started, CLI commands, composition, providers, Jev, and bounded collection reduction.
- Runnable examples cover concurrent map evaluation, release readiness, and a bounded read-only Jev plus Playwright CLI browser loop.
- Safe verbose traces remain separate from JSON and NDJSON output and support concurrent evaluations.

## Install

Download the archive for your platform from this GitHub release and verify it with `checksums.txt`. Archives are available for:

- Linux amd64
- Linux arm64
- macOS amd64
- macOS arm64

From a tagged source checkout:

```sh
nix run . -- version
nix profile install .#jeq
```

On supported Linux systems, the repository also includes `scripts/install-jeq-linux.sh`.

## Upgrade notes

- Existing `ask`, `map`, `rate`, `rank`, `reduce`, `gate`, and `validate` request shapes remain available.
- NDJSON `map` output remains in input order, but several provider requests can now be active concurrently.
- Keep `set -o pipefail` in shell pipelines so provider, policy, and projection failures remain visible.
- Check provider selection with `jeq models` and inspect the provider guide before moving credentials or CI configuration.
- Use `jeq <command> --help` and `jeq examples <command>` instead of copying stale invocation syntax.

## Known limitations

- TypeSafe access requires configured credentials. Judgment commands make network requests and can incur cost.
- The browser example is a bounded read-only demonstration, not a general autonomous browser or a reliability claim.
- Windows artifacts, signing, provenance attestations, Homebrew, and nixpkgs publication remain out of scope.
- Choice probabilities are relative. They are not independent confidence scores.
- Release candidates do not promise stable command or evidence contracts. Inspect typed evidence before using it for automation.
